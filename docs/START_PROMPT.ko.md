아래를 복사한 뒤 마지막에 실제 문제 원문과 채점 조건을 붙여 넣으세요.

```text
이 저장소에서 아래 시험 문제를 구현해 줘. 기본 6.1 Sol과 제공된 Codex 버전을 유지하고 업데이트하지 마.
우선 AGENTS.md, package.json, README.md, src/starter, src/shared, src/domain을 확인해.
스킬이 표시되지 않아도 필요한 경우 .agents/skills/*/SKILL.md를 직접 읽고 진행해.

순서: 요구사항 정리 → 최소 구현 → 실행 → 브라우저 검증 → 수정 → 최종 확인.
문제 원문에서 입력·출력·필수 기능·제약·합격 조건을 추려 짧게 적고, 불명확한 부분은 가정으로 표시해.
src/practice는 연습 예제다. 답안은 src/starter/Starter.jsx부터 직접 구현하고,
src/shared의 작은 도구만 필요한 만큼 재사용해. src/domain의 예제 규칙과 샘플 데이터를 실제 문제에 맞게 바꿔.
구현·설치는 시험이 허용한 범위만 사용하고, 설치 권한이 없으면 가능한 부분부터 진행해.

npm ci로 잠금 버전을 설치하고 npm run dev로 0.0.0.0:3000에 실행해.
포트 충돌 시 소유 프로세스를 먼저 확인하고 다른 포트로 자동 전환하지 마.
Playwright MCP로 http://localhost:3000의 구조 읽기·입력·클릭·스크린샷·콘솔 오류를 실제 확인해.
미리보기와 MCP가 같은 서버인지 /__server_identity와 화면의 '서버 확인' ID를 비교해.
MCP가 없으면 README의 연결 절차를 사용해. 설치가 금지되면 그 제약을 기록하고 허용된 브라우저나 테스트로 검증해.
핵심 성공 경로, 빈 입력, 잘못된 파일, 검색 결과 없음, 추가·수정·삭제, 필요한 영속성을 확인해.
문제별 Playwright 테스트도 수정하고 실행해. 구현과 관계없는 연습 예제 테스트 통과만으로 답안 완성을 주장하지 마.
완료할 때 변경 파일, 실행 명령과 결과, 실패·미검증 항목을 짧게 보고해.
```
